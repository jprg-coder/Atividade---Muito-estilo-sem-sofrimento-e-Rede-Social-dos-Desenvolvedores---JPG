# FinControl Gothic - Projeto Fintech

Tela única responsiva desenvolvida com HTML, CSS separado e Tailwind CSS via CDN.

## Arquivos

- `index.html`: tela principal do projeto.
- `css/style.css`: identidade visual, responsividade complementar e estilos próprios.
- `assets/logo-fincontrol.svg`: logo local.
- `assets/gothic-pattern.svg`: textura local usada no fundo.
- `Link_GitHub_Template.pdf`: modelo para inserir o link público do repositório.

## Como abrir

Abra o arquivo `index.html` diretamente no navegador.
